# learn

按 ICAP（Passive → Active → Constructive）学习 `knowledge/books/<书名>/` 下的知识点，并把笔记与进度持久化。

## 开始前

1. 读 `knowledge/books/<书名>/base.md`；缺失则提示先用 `/decode-book <书名>`，停止。
2. 读 `knowledge/books/<书名>/progress.md`；缺失则新建（总知识点数 = `base.md` 的 `##` 分节数，当前知识点 = 1，已完成 = 空）。
3. 从 `progress.md` 读出「当前知识点」，定位 `base.md` 里对应的分节。

## 每个知识点的流程

对当前知识点，按下面三步依次进行；每一步达标后才进入下一步。

### Step 1 — Passive：展示
原样呈现该知识点的标题与正文。

### Step 2 — Active：笔记与校验
1. 请用户基于该知识点写出自己的笔记。
2. 对照 `base.md` 该节原文校验笔记：
   - 正确 → 进入第 3 步整理。
   - 有误 → 指出具体错误与原文依据，请用户修改后重新提交，重复到正确为止。
3. 整理最终笔记，追加写入 `note.md`。

### Step 3 — Constructive：建构
1. 请用户用自己的话解释该知识点，并举一个自己的例子。
2. 主动向用户提 1~2 个问题，或解答用户的提问。
3. 把解释、举例、问答整理后追加写入 `note.md`。

## 文件格式

`note.md`（累加）：

    # <书名> 学习笔记
    ## <知识点序号>. <标题>
    ### 笔记（Active）
    - ...
    ### 建构（Constructive）
    - 解释：...
    - 举例：...
    - 问答：Q / A

`progress.md`（每学完一个知识点更新一次）：

    # 学习进度
    书名: <书名>
    总知识点数: N
    当前知识点: <序号>. <标题>
    已完成: <序号列表>

## 续学

学完当前知识点并保存进度后，问用户「继续下一个知识点？」；继续则回到「每个知识点的流程」，否则停止。用户说「继续」时，读 `progress.md` 续学到下一个未完成知识点；全部完成则提示并停止。

## 完成标准

当前知识点的笔记已校验通过并写入 `note.md`，建构记录已写入，`progress.md` 已推进到下一知识点。
